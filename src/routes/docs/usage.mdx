# Usage

Start Zenkai from a terminal, or better, [bind it to a hotkey](/docs/hotkeys) in your desktop or window manager:

```bash
zenkai
```

Start typing and the list filters as you go. Press **Enter** to open the selected result, **Ctrl+K** for its actions, and **Esc** to close.

## What you can type

Everything shares one search bar. Plain text searches your apps; a prefix or a recognizable pattern switches to something else.

## Launch modes

The same binary can start in a few different modes:

<Table>
  <tr>
    <Th>Command</Th>
    <Th>Mode</Th>
  </tr>
  <tr>
    <Td>`zenkai`</Td>
    <TdDesc>Normal launcher with apps, plugins and `win:` window search.</TdDesc>
  </tr>
  <tr>
    <Td>`zenkai --window-switcher`</Td>
    <TdDesc>Dedicated window switcher. Windows are listed right away and typing filters them without `win:`.</TdDesc>
  </tr>
  <tr>
    <Td>`zenkai --run`</Td>
    <TdDesc>Windows only: a Run box that opens the typed command or URL with the Windows shell.</TdDesc>
  </tr>
  <tr>
    <Td>`zenkai --no-dapps --plugin=calculator`</Td>
    <TdDesc>Plugin-only mode, here a standalone calculator.</TdDesc>
  </tr>
  <tr>
    <Td>`zenkai --theme=launchpad --fullscreen`</Td>
    <TdDesc>Fullscreen icon grid with a pill-shaped search bar.</TdDesc>
  </tr>
</Table>

## The actions menu

Press **Ctrl+K** on any result to open a searchable menu of things you can do with it. Type to filter, use Up/Down to pick one and Enter to run it.

- **Apps:** Copy Name, Copy Launch Command, plus New Window and New Private Window for browsers
- **Windows:** Switch to Window, Copy Window Title, Left/Right/Top/Bottom Half, Maximize, Center Window, Move to Next Display
- **Files and folders:** Open, Reveal in File Manager, Copy Path, New File, New Folder, Rename, Move to Trash
- **URLs and quicklinks:** Copy URL
- **Snippets:** Copy Snippet
- **Calculator:** Copy Result, Copy Expression

The bottom bar shows the main actions too. Hide it with `--no-bottom-bar`; Ctrl+K still works.

## More examples

```bash
# Dracula theme, bigger icons, wider window
zenkai --theme=dracula --size=48 --width=800

# Show file previews, with room for them
zenkai --file-previews --width=900

# Custom entries only, no app scanning
zenkai --menu="Firefox|firefox|firefox" --menu="Terminal|alacritty|terminal"

# Minimal look
zenkai --no-icons --no-bottom-bar

# Close when you click outside
zenkai --close-on-focus-out
```
