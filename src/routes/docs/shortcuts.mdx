# Keyboard Shortcuts

Zenkai is built to be used without a mouse. On macOS, Ctrl+P is **Command+P**.

## Tips

- The search is fuzzy, so you rarely need the full name
- Clear the search back to `win:` to refresh the window list
- Plugins can react to keys with the `on_keypress(key)` hook
