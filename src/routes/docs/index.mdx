# Overview

Zenkai is a fast, keyboard-driven launcher for **Linux**, **macOS** and **Windows**, written in **Zig** with **Qt6**.

One search bar finds your apps, switches between open windows, browses and previews files, does math and unit conversions, and runs anything you add with a Lua plugin.

## What can it do?

- **Launch apps** - fuzzy search across .desktop files on Linux and Start Menu shortcuts on Windows
- **Switch windows** - type `win:` to focus any open window, then snap it to a half, maximize it or move it to another display
- **Browse files** - type a path like `~/Documents`, or `file: report` to search filenames
- **Preview files** - text, code with syntax colors, images and folder listings with **Ctrl+P**
- **Act on results** - **Ctrl+K** opens an actions menu: copy paths, rename, move to trash, open a private browser window and more
- **Calculate** - scientific math, unit conversions and currency rates
- **Quicklinks and snippets** - `link:` searches the web or your saved links, `snip:` copies saved text
- **Emoji** - `:fire` finds any emoji by name or keyword and copies it
- **Themes** - 65+ built-in themes, or write your own in QSS
- **Extend** - Lua plugins with hooks for queries, actions and previews
