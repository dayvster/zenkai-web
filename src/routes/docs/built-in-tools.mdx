# Built-in Tools

Zenkai ships with a set of Lua plugins that turn the search bar into more than an app launcher. Disable all of them with `--no-plugins`, or load only some with `--plugin=NAME`.

## Calculator

Type an expression and the answer shows up as a result. Enter copies it and keeps Zenkai open; Ctrl+K also offers Copy Expression.

Supports length, mass, time, volume, speed, temperature, angles and data sizes. Data units tell bits (`Mb`) from bytes (`MB`) and decimal from binary (`MiB`).

Currency rates come from [Frankfurter](https://frankfurter.dev/), which publishes daily reference rates (not live trading prices). Only the currency codes are sent, never the amount. Rates are cached until Zenkai closes. Everything else works offline.

## Quicklinks

Type `link:` and a search to search Google or GitHub, or to find one of your saved links by title.

Add your own by copying the plugin's `config.example.json` to `~/.config/zenkai/quicklinks.json` (`%APPDATA%\zenkai\quicklinks.json` on Windows). Each entry under `commands` has a `title` and an `http(s)` `url`. A `{query}` placeholder in the URL is replaced with what you typed. Set `"replace": true` to drop the built-in Google and GitHub searches.

## Snippets

Type `snip:` to find a saved snippet by title or description. Enter copies its text (it doesn't type it into another app).

Snippets live in `snippets.json` in the same config folder. Each one has a `title`, an optional `subtitle` and the `text`. Use `\n` for line breaks.

## URL suggestions

Type something that looks like a URL, such as `github.com` or `localhost:3000`, and Zenkai offers to open it in your default browser, shown with that browser's icon. Bare domains open over HTTPS and `localhost` with a port over HTTP. Normal multi-word searches and email addresses are ignored.
