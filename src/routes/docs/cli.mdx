# CLI Flags

Every setting can be passed on the command line. Flags override [zenkai.conf](/docs/configuration). Run `zenkai --help` for the same list in your terminal.

## Modes

<Table>
  <tr>
    <Th>Flag</Th>
    <Th>Value</Th>
    <Th>Description</Th>
  </tr>
  <tr>
    <Td>--window-switcher</Td>
    <Td>-</Td>
    <TdDesc>Start as a window switcher with open windows already listed</TdDesc>
  </tr>
  <tr>
    <Td>--no-window-switcher</Td>
    <Td>-</Td>
    <TdDesc>Turn off the built-in `win:` window search</TdDesc>
  </tr>
  <tr>
    <Td>--run</Td>
    <Td>-</Td>
    <TdDesc>Windows only: open Run mode and run the typed command or URL</TdDesc>
  </tr>
  <tr>
    <Td>--no-dapps</Td>
    <Td>-</Td>
    <TdDesc>Skip app scanning (for plugin-only or `--menu` setups)</TdDesc>
  </tr>
  <tr>
    <Td>--menu</Td>
    <Td>name|cmd|icon</Td>
    <TdDesc>Add a custom entry. Repeatable. Skips app scanning</TdDesc>
  </tr>
</Table>

## Examples

```bash
# Window switcher on a hotkey
zenkai --window-switcher

# Dracula theme, bigger icons, wider window
zenkai --theme=dracula --size=48 --width=800

# File previews with room for them
zenkai --file-previews --width=900

# Fullscreen icon grid on the second monitor
zenkai --theme=launchpad --fullscreen --monitor=1

# Custom menu, no app scanning
zenkai --menu="Firefox|firefox|firefox" --menu="Terminal|alacritty|terminal"

# Calculator only
zenkai --no-dapps --plugin=calculator

# Copy URLs to the clipboard instead of opening them
zenkai --clipboard="wl-copy"

# Hot-reload a theme you're working on
zenkai --debug --theme-reloader --theme=./my-theme.qss
```
